# RACI责任矩阵构建技能（raci-matrix）

> 主色：`#C8102E` ｜ 类型：交互引导式（分析/规划类，强制交互锁）

## 一句话简介
交互引导式为质量活动与过程定义 RACI 责任矩阵（R 负责 / A 问责 / C 咨询 / I 知会），**不替用户代填**，收集后自动推导矩阵。

## 适用角色
项目经理、质量经理、过程所有者、跨部门协作负责人。

## 何时使用
- 定义质量活动/过程（审核、客诉、变更等）中"谁该干什么"；
- 跨部门职责扯皮、责任真空；
- 新建流程/重组团队，需明确责任边界；
- 质量体系职责梳理、管理评审输入。

## 三道强制交互锁
1. **门1 活动清单**：列出待分配责任的活动/过程；
2. **门2 角色清单**：列出参与岗位/角色；
3. **门3 逐格指派**：对每个(活动×角色)由用户指派 R/A/C/I。

## 产出物
`RACI责任矩阵.md`：矩阵表 + 规则校验提示 + 使用说明。

## 使用方式
在对话中按三道门逐项提供信息，Agent 仅提示规则、不代填；收集完成后自动排布矩阵供确认。

## 设计规范
- 简体中文文档，代码标识符英文；
- 主色 `#C8102E`；
- 防幻觉：未提供项标「待企业补充」；
- 去商业化：无营销人设、无付费引导；
- 强制交互锁：Agent 绝不替用户决定任何单元格。
